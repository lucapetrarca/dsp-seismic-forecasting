# dsp-seismic-forecasting
Este proyecto desarrolla un pipeline de DSP para la detección temprana de terremotos en entornos de alto ruido de fondo. Utilizando el Stanford Earthquake Dataset, el sistema identifica ondas sísmicas P ocultas en ruido microsísmico y antropogénico, para luego pronosticar la amplitud pico de la onda S mediante modelos de Deep Learning.
